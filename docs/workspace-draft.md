# penta J — 5인 공유 워크스페이스 초안

상태: 논의용 초안. 실제 Notion 생성 및 ChatGPT 연결은 아직 수행하지 않았다.

## 1. 확정된 방향

- 참여 인원: 5명
- 장기 목표: MCN 기업 설립
- 초기 축 A: AI 분야를 시작으로 UGC 크리에이터 계정 육성
- 초기 축 B: 인플루언서 1명 육성 및 운영 사례 확보
- 먼저 할 일: 5명이 업무와 진행 상황을 공유하는 운영 시스템 구축

두 축의 시작 시점과 담당자는 미정이다. UGC가 브랜드 납품 콘텐츠를 뜻하는지, 자체 계정의 콘텐츠를 뜻하는지도 확인이 필요하다.

## 2. 최소 Notion 구성

### 팀 홈

이번 주 핵심 목표 최대 3개, 업무 보드, 콘텐츠 보드, 막힌 일, 주간 회의 기록으로 연결한다. 멤버 목록에는 이름/별칭, 역할, 주당 가능 시간을 기록한다.

### 업무 보드 — 데이터베이스 1

필드: 업무명 / 사업 축 / 담당자 1명 / 검토자 / 마감일 / 상태 / 완료 기준 / 결과 링크 / 막힌 이유.

상태: 대기 → 진행 → 검토 → 완료. 진행을 못 하는 업무는 별도의 막힘 표시와 필요한 지원을 기록한다.

보기: 전체 보드, 내 업무, 이번 주 마감, 막힌 업무.

하나의 업무에는 최종 책임자가 한 명 있어야 한다. 완료 기준은 결과물 또는 확인 가능한 행동으로 작성한다.

### 콘텐츠 보드 — 데이터베이스 2

필드: 콘텐츠명 / 운영 계정 / 플랫폼 / 타깃·주제 / 제작 담당 / 게시 예정일 / 상태 / 원본·게시 링크 / 게시 후 지표.

상태: 아이디어 → 기획 → 제작 → 검토 → 게시 → 회고.

플랫폼이 정해지면 조회수, 시청 유지 또는 참여율, 팔로워 변화, 협업 문의 중 첫 목표에 맞는 지표만 선택한다. 계정별 출발 수치도 기록한다.

### 주간 회의 기록

주 1회 30분을 기본안으로 한다. 이번 주 결과, 막힌 일, 결정과 이유, 다음 주 담당자와 마감일을 기록한다. 중요한 결정은 개인 채팅에만 남기지 않는다.

## 3. 역할을 배정할 때 사용할 책임 영역

| 책임 영역 | 주된 책임 |
| --- | --- |
| 총괄·운영 | 우선순위, 일정, 예산, 의사결정 기록 |
| AI·리서치 | 콘텐츠 조사, AI 제작 방식, 향후 자동화 |
| 콘텐츠 제작 | 대본, 촬영, 편집, 결과물 관리 |
| 채널·성장 | 게시, 계정 운영, 성과 분석 |
| 크리에이터·사업 | 인플루언서 협업, 브랜드 접점, 수익화 조사 |

이는 사람별 확정 배정이 아니다. 실제 강점과 가능 시간을 확인하고, 겸임과 검토자를 정한다. 주간 회의에서는 업무 진행과 필요한 지원을 확인한다.

## 4. 공유와 AI 연결

- Notion을 운영 기록의 기준 공간으로 사용한다.
- Notion 관리자와 대체 관리자 1명을 정하고, 나머지 멤버에게 필요한 편집 권한을 준다.
- 외부 협업자는 필요한 페이지에만 초대한다. 계약·개인 정보 등은 접근 범위를 별도로 정한다.
- ChatGPT 구독과 Notion 요금제·멤버 권한은 별개다. 개인 유료 ChatGPT 구독만으로 5인 공유 워크스페이스가 자동 생성되지는 않는다.
- 각자의 계정을 사용하고, 연결 기능은 해당 계정에서 제공되는 앱과 관리자 정책을 확인한다.
- 실제 Notion 읽기·쓰기·자동화 범위와 요금은 현재 플랜 확인 후 결정한다. 연결만으로 업무 보드가 자동 생성·갱신된다고 가정하지 않는다.
- AI 기획 결과, 검토한 내용, 최종 결정은 Notion에 기록한다. 개인 채팅만을 팀 기록으로 사용하지 않는다.

## 5. 먼저 필요한 정보

1. 5명의 이름/별칭, 강점, 주당 투입 가능 시간. 인플루언서 후보가 정해져 있는지도 확인한다.
2. 첫 8주에 쓸 수 있는 예산과 성공 기준. 8주는 논의용 기준이며 확정 일정이 아니다.
3. 첫 플랫폼, 콘텐츠 언어, 타깃. UGC는 브랜드 납품인지 자체 계정 육성인지 확인한다.
4. 기존 Notion 워크스페이스 유무·요금제·관리자와 현재 ChatGPT 요금제. 5명이 같은 플랜을 쓰는지도 확인한다.

미정인 항목은 미정으로 기록한다. 이 정보를 받은 뒤 역할·초기 목표·권한·연결 방식을 구체화한다.
