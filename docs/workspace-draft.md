# penta J — 5인 공유 워크스페이스 초안

상태: 논의용 초안. 실제 Notion 생성 및 ChatGPT 연결은 아직 수행하지 않았다.

## 1. 확정된 방향

- 참여 인원: 개안·찬·리트리버·당근·업사, 5명
- 장기 목표: MCN 기업 설립
- 초기 축 A: AI 분야를 시작으로 인스타그램 릴스 계정을 육성하고, 체급과 실적을 확보한 뒤 브랜드에 UGC 콘텐츠 납품을 역제안
- 초기 축 B: 인플루언서 1명 육성 및 운영 사례 확보
- 먼저 할 일: 5명이 업무와 진행 상황을 공유하는 운영 시스템 구축
- 초기 기간: 30일. 목표 방향은 지속적이고 빠른 성장
- 추가 사업 예산: 0원. 기존 ChatGPT Pro 월 200달러 구독 활용
- 기존 Notion 워크스페이스: 없음. 새로 생성 필요
- 향후 운영 구상: 합숙, 공동 작업, 상호 점검, 벌금 제도

사람별 강점과 주당 가능 시간, 언어·타깃, 수치 목표, 인플루언서 후보는 미정이다. 첫 30일은 공동 실험 계정 1개에 집중하는 방식을 제안하되, 운영 계정 수는 아직 확정하지 않는다.

## 2. 최소 Notion 구성

### 팀 홈

이번 주 핵심 목표 최대 3개, 업무 보드, 콘텐츠 보드, 막힌 일, 주간 회의 기록으로 연결한다. 멤버 목록에는 이름/별칭, 역할, 주당 가능 시간을 기록한다.

### 업무 보드 — 데이터베이스 1

필드: 업무명 / 사업 축 / 담당자 1명 / 검토자 / 마감일 / 상태 / 완료 기준 / 결과 링크 / 막힌 이유.

상태: 대기 → 진행 → 검토 → 완료. 진행을 못 하는 업무는 별도의 막힘 표시와 필요한 지원을 기록한다.

보기: 전체 보드, 내 업무, 이번 주 마감, 막힌 업무.

하나의 업무에는 최종 책임자가 한 명 있어야 한다. 완료 기준은 결과물 또는 확인 가능한 행동으로 작성한다.

### 콘텐츠 보드 — 데이터베이스 2

필드: 콘텐츠명 / 운영 계정 / 플랫폼 / 타깃·주제 / 제작 담당 / 게시 예정일 / 상태 / 원본·게시 링크 / 게시 후 지표.

상태: 아이디어 → 기획 → 제작 → 검토 → 게시 → 회고.

플랫폼은 인스타그램 릴스다. 게시 수, 게시 후 같은 시점의 조회수, 확인 가능한 시청 유지 지표, 저장·공유, 순증 팔로워를 기록한다. 브랜드 제안을 시작하면 제안 수·답변 수·유효 문의도 기록한다. 계정별 출발 수치를 먼저 확인하고, 첫 주 결과로 30일 수치 목표를 정한다.

### 주간 회의 기록

주 1회 30분을 기본안으로 한다. 이번 주 결과, 막힌 일, 결정과 이유, 다음 주 담당자와 마감일을 기록한다. 중요한 결정은 개인 채팅에만 남기지 않는다.

## 3. 역할을 배정할 때 사용할 책임 영역

| 책임 영역 | 주된 책임 |
| --- | --- |
| 총괄·운영 | 우선순위, 일정, 예산, 의사결정 기록 |
| AI·리서치 | 콘텐츠 조사, AI 제작 방식, 향후 자동화 |
| 콘텐츠 제작 | 대본, 촬영, 편집, 결과물 관리 |
| 채널·성장 | 게시, 계정 운영, 성과 분석 |
| 크리에이터·사업 | 인플루언서 협업, 브랜드 접점, 수익화 조사 |

이는 사람별 확정 배정이 아니다. 실제 강점과 가능 시간을 확인하고, 겸임과 검토자를 정한다. 주간 회의에서는 업무 진행과 필요한 지원을 확인한다.

멤버 5명의 강점·가능 시간·역할은 모두 미정으로 등록한다. 이름만으로 역할을 임의 배정하지 않는다.

### 상호 점검·벌금 규칙 초안

초기 상호 점검은 하루 한 번 완료한 일·다음 할 일·막힌 일을 기록하고, 검토자가 결과 링크를 확인하는 방식으로 제안한다.

벌금은 아직 도입하지 않았다. 적용하려면 대상 행동, 완료 기준, 증빙, 예외·기한 변경, 금액·상한, 이의 제기, 보관 담당자·사용처를 문서화하고 5명이 합의한다. 실제 지급·수납은 이번 세팅에 포함하지 않는다. 합숙 장소·기간·비용도 별도로 결정한다.

## 4. 공유와 AI 연결

- Notion을 운영 기록의 기준 공간으로 사용한다.
- Notion 관리자와 대체 관리자 1명을 정하고, 나머지 멤버에게 필요한 편집 권한을 준다.
- 외부 협업자는 필요한 페이지에만 초대한다. 계약·개인 정보 등은 접근 범위를 별도로 정한다.
- ChatGPT 구독과 Notion 요금제·멤버 권한은 별개다. 개인 유료 ChatGPT 구독만으로 5인 공유 워크스페이스가 자동 생성되지는 않는다.
- 현재 보유한 구독은 개인 ChatGPT Pro다. 다른 4명의 구독과 접근 권한은 아직 확인하지 않았다.
- 추가 예산이 없으므로 Notion 무료 범위와 필요한 페이지의 게스트 초대를 먼저 검토한다. 무료 플랜의 멤버·게스트·블록 제한은 실제 가입 화면에서 확인하고, 유료 전환은 확정하지 않는다.
- 각자의 계정을 사용하고, 연결 기능은 해당 계정에서 제공되는 앱과 관리자 정책을 확인한다.
- 실제 Notion 읽기·쓰기·자동화 범위와 요금은 현재 플랜 확인 후 결정한다. 연결만으로 업무 보드가 자동 생성·갱신된다고 가정하지 않는다.
- AI 기획 결과, 검토한 내용, 최종 결정은 Notion에 기록한다. 개인 채팅만을 팀 기록으로 사용하지 않는다.

## 5. 남은 결정

1. 사람별 강점·주당 가능 시간, 총괄·검토자, Notion 소유자·대체 담당자.
2. 기존 인스타그램 계정 유무, 운영 계정 수, 콘텐츠 언어·타깃, 인플루언서 후보.
3. 첫 주 관찰 결과에 기반한 30일 목표 수치와 제작 가능한 게시량.
4. 새 Notion 워크스페이스 생성과 5명 초대. 각자의 ChatGPT 앱 화면에서 제공되는 Notion 연결 확인.
5. 상호 점검·벌금의 구체적인 운영 규칙. 합숙은 추후 별도 결정.

이미 받은 정보는 다시 묻지 않는다. 미정인 항목은 미정으로 기록하고, 초기 업무 보드에서 결정한다.
