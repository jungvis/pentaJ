# penta J

5명이 함께 시작하는 크리에이터 사업 프로젝트.

장기 목표는 MCN 기업 설립이다. 초기에는 AI 분야의 UGC 크리에이터 계정과 인플루언서 1명의 성장 사례를 만들고, 검증된 제작·운영 방식으로 사업을 확장한다.

## 지금 준비하는 것

- Notion: 팀 업무, 콘텐츠 제작, 계정 성장 지표, 의사결정의 공유 공간
- ChatGPT: 기획·리서치·작성 지원. 결과와 결정은 공유 문서에 기록
- GitHub: 운영 문서와 향후 자동화 코드의 버전 관리

[5인 워크스페이스 초안](docs/workspace-draft.md)을 기준으로 첫 운영 구조를 정한다. 이 문서는 초안이며, 역할 배정·예산·목표 수치는 아직 확정하지 않았다.

현재 저장소에는 애플리케이션과 의존성이 없다. 설치·빌드 명령은 아직 필요하지 않다.

## 작업 원칙

- 기존 클라우드 체크아웃을 사용한다. 별도 worktree는 명시적으로 요청할 때 만든다.
- 확정 사항과 제안을 구분하고, 중요한 변경은 기록한다.
- 계정 비밀번호, API 키, 계약서 및 개인 정보는 저장소에 올리지 않는다.
- Notion과 ChatGPT의 계정·권한은 개인별로 부여한다.
