# penta J

개안·찬·리트리버·당근·업사, 5명이 함께 시작하는 크리에이터 사업 프로젝트.

장기 목표는 MCN 기업 설립이다. 초기에는 AI 분야를 시작으로 인스타그램 릴스 계정을 직접 육성하고, 성장 실적을 기반으로 브랜드에 UGC 콘텐츠 납품을 역제안한다. 인플루언서 1명의 성장 사례도 만들어 사업을 확장한다.

첫 운영 기간은 30일, 추가 사업 예산은 0원이다. 기존 ChatGPT Pro 구독을 활용한다. 성장의 구체적인 수치 목표와 사람별 역할은 미정이다.

## 지금 준비하는 것

- Notion: 팀 업무, 콘텐츠 제작, 계정 성장 지표, 의사결정의 공유 공간
- ChatGPT: 기획·리서치·작성 지원. 결과와 결정은 공유 문서에 기록
- GitHub: 운영 문서와 향후 자동화 코드의 버전 관리

[5인 워크스페이스 초안](docs/workspace-draft.md)을 기준으로 첫 운영 구조를 정한다. [Notion 생성·가져오기 안내](docs/notion-setup.md)와 [가져오기용 CSV](notion-import/)를 준비했다. 실제 Notion 워크스페이스와 ChatGPT 연결은 아직 생성하지 않았다.

Notion API 접근이 준비되면 [자동 설정 도구](scripts/setup_notion.py)로 멤버·업무·콘텐츠 보드와 운영 페이지를 만들 수 있다. 인증 없는 로컬 입력 검증은 `python3 scripts/setup_notion.py --dry-run`으로 실행한다. 실제 API 생성은 아직 검증하지 않았다.

현재 저장소에는 애플리케이션과 의존성이 없다. 설치·빌드 명령은 아직 필요하지 않다.

## 작업 원칙

- 기존 클라우드 체크아웃을 사용한다. 별도 worktree는 명시적으로 요청할 때 만든다.
- 확정 사항과 제안을 구분하고, 중요한 변경은 기록한다.
- 계정 비밀번호, API 키, 계약서 및 개인 정보는 저장소에 올리지 않는다.
- Notion과 ChatGPT의 계정·권한은 개인별로 부여한다.
